# 局域网共享播放

## 使用

在设置的「局域网共享」中选择当前电脑的私有 IPv4 网卡、端口和索引中的文件夹。勾选文件夹授权其所有后代；可只勾选子目录。支持最多 64 个目录授权，默认 6 台设备，设备上限可设置为 1–16 台。

开启后，手机扫描二维码，浏览器自动验证并进入共享目录，无需输入配对码或设备名称。二维码包含 256 位随机授权凭证，10 分钟后过期；电脑端可刷新二维码，旧二维码／连接链接随即失效，已授权设备继续使用。连接后设备会话持续 24 小时；重新扫描或刷新页面复用已有会话，不增加设备名额。设备名称由浏览器环境生成。

直接打开普通共享网址只显示扫码提示，不能访问资源。电脑端「复制连接链接」复制与二维码相同的完整授权链接，适合其他电脑使用。二维码和完整链接均代表访问权限，获得者可在有效期内连接，请只向可信设备展示或发送。电脑端可查看设备名称、网络地址、最近访问和播放内容，并撤销单台设备。撤销设备会同时轮换二维码，原扫码链接不能再次取得授权，其他已授权设备不受影响。

浏览器可以搜索文件名或标签、按类型筛选、分页浏览、预览图片、前后切换视频和使用浏览器视频控件。视频直接传输原文件；浏览器支持 MP4、WebM 等格式的具体编码组合，需以访问设备实测为准。本版没有服务端转码、转封装或外置字幕转换。续播保存在浏览器本地存储中，按媒体库、媒体 ID 与内容修订区分，不更新桌面端 `entries.playback`。

共享默认关闭；只记住配置，不记住二维码凭证和授权会话，应用重启后需要重新开启并扫码。可以在开启前选中「关闭窗口后继续共享」，此时关闭主窗口隐藏到系统托盘。托盘菜单可打开窗口或停止共享并退出。电脑休眠、退出、切换媒体库、移除或重绑根目录会中断共享；根目录迁移需要重新授权设备。

## 连接故障

- `127.0.0.1` 是仅本机预览地址，手机应使用电脑端列出的私有网卡地址。
- 两台设备需要网络可互访。访客 Wi-Fi 的客户端隔离可能阻止连接。
- 检查 Windows 防火墙的专用网络权限。程序不自动修改防火墙、系统网络配置或路由器端口映射。
- 地址变化后停止共享，重新选择网卡并开启；端口冲突会显示原因，可修改监听端口。
- 二维码无效或过期时，电脑端点击「刷新二维码」，手机重新扫描；撤销设备会自动更换二维码。
- 无访问权限时使用电脑端二维码；普通网址、旧版本的手动配对码和只复制 IP／端口均不能授权。扫码工具需要保留链接的 `#connect=…` 部分。
- 离线磁盘保留目录与已缓存封面，原文件播放提示资源不可用。
- 浏览器提示无法解码时可换浏览器或回到桌面端 mpv；本版不会后台自动转码。

本版使用 HTTP，只在可信局域网使用。扫码授权是访问控制，不提供传输加密；不含 HTTPS 证书配置、DLNA 或公网访问配置。只监听选定的私有 IPv4 网卡或本机地址，不绑定全部网卡。

## 实现

共享只在开启时启动两个 Electron utility processes：网络服务及专用只读数据库查询。桌面浏览仍使用自己的查询进程；主库写入仍由原有数据库写入服务管理。停止时关闭监听连接、撤销设备、释放媒体租约与这两个进程。

共享范围由服务端维护，网络请求不能提交授权目录数组、磁盘路径、SQL 或桌面 IPC 方法。目录、搜索、封面、原文件和播放活动均检查授权范围。范围判断使用目录闭包表，搜索与计数在授权条件之后执行；查询在读取事务中生成一致的分页结果，面包屑从已共享祖先开始。网络 DTO 不包括本机路径、身份、来源封面关联、桌面播放进度或设置。

网络文件服务通过现有 `MediaService` 创建租约；打开原文件后复核文件身份，支持 GET、HEAD、单段 Range、206 和 416，按流传输并在断开时关闭文件。原文件读取与网络流在共享进程处理；缩略图使用既有缓存和后台优先级，租约覆盖传输生命周期以防缓存淘汰删除正在访问的文件。

二维码凭证为 256 位随机值，放在 URL 的 `#connect=…` 片段中。片段不会随页面／静态资源请求发送，见 [MDN URL 片段说明](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment)。浏览器读取后立即通过 `history.replaceState` 清理地址栏，再用 `/api/connect` 的 JSON POST 换取另一份独立的设备凭证；查询参数、普通 GET 与旧 `/api/pair` 均不能授权。二维码凭证不写入本地存储、不放入资源 URL 或会话响应，设备 Cookie 不同于二维码凭证。

设备凭证也为 256 位随机值，通过 HttpOnly、SameSite=Strict Cookie 发送，服务端会话表仅保存摘要；服务运行时保留二维码图像与完整连接链接供可信的桌面界面显示，校验使用摘要。连接尝试按来源与全局限速，在请求正文读取完成后检查凭证有效期。固定 Host、同源 Origin 检查、静态资源白名单和 CSP 限制页面来源。未提供远程文件修改接口。撤销、会话过期和停止会关闭设备尚未完成的响应；已下载到客户端的内容无法收回。

服务限制 128 个连接、24 个并行文件请求、每台设备 12 个进行中的请求、8 个并行查询；请求正文最多 2 KiB，静态资源直接随安装包分发，无 CDN 或第三方访问。

## 验证

```powershell
npm run build
npm test
npm run test:sharing
```

打包程序的回归：

```powershell
$env:VM_TEST_EXECUTABLE = (Resolve-Path release/win-unpacked/VideoManager.exe).Path
$env:VM_UI_LABEL = 'packaged'
npm run test:sharing
```

脚本使用 `.test-data` 中的隔离媒体库，不启动个人媒体库。使用 Playwright、真实 Windows Electron 与已安装 Chrome；可用 `VM_BROWSER_CHANNEL=msedge` 切换到已安装 Edge。手机为触屏视口模拟，物理 Android、iPhone、二维码扫描工具、跨机器防火墙与实际 Wi-Fi 吞吐量需要设备验收。完整测试记录见 [v0.10.1 验收记录](RELEASE_v0.10.1.md)。
